# 双人演示指南

这是参考世界验收使用的可复现衍生闭环。它运行在真实 Compose 栈上：PostgreSQL、Go API、生产 Web 构建，以及两个真正独立的浏览器身份。固定演示模式是确定性且有明确标记的，不是真实 AI。

## 前置条件

- Docker Engine 与 Compose v2。
- 两个独立浏览器配置，或两个隐私窗口。自动化套件使用两个隔离的 Playwright 浏览器上下文。
- 固定演示模式不需要模型 API Key。

## 启动

```bash
cp .env.example .env
docker compose up --build -d
curl -fsS http://127.0.0.1:8080/readyz
```

在两个配置中打开 <http://127.0.0.1:8080>。顶部显示 `FIXTURE`。

## 场景 A — 协作对象

1. **A** 在**创建你的数字自我**注册。欢迎页确认真实注册事务创建的数字自我与个人 AI。
2. **A** 打开**世界 → 创建第一个对象**，选择**协作对象**并创建文档。
3. **A** 修改正文，顶部版本从 v1 变为 v2。
4. **A** 打开**成员与权限**，创建包含**读取、贡献、衍生**的邀请。复制链接；它只显示一次。
5. **B** 在第二个配置打开链接，选择**创建账户**，注册后回到邀请并接受。
6. **B** 在独立会话中修改正文。
7. **A** 点击**刷新**。正文变化和新版本可见；它来自 PostgreSQL，而不是本地回显。
8. **B** 点击**衍生一个分支**，命名并提交。子对象是 v1 的独立对象。**B** 打开**查看谱系**，看到源对象。

预期：两个独立身份、一个权威对象、B 持久化的 v3 修改，以及一个记录源版本的衍生子对象。

## 场景 B — 互动对象

1. **A** 创建带三个选项的**互动对象**。
2. **A** 以读取、贡献、衍生权限邀请 **B**。
3. **B** 投票；选中项标记**你**，计数为 1。
4. **B** 改投另一项；第一项回到 0，第二项变为 1。只有一张回执移动。
5. **A** 刷新看到相同计票，然后关闭投票。
6. **B** 刷新；选项禁用，投票已关闭。
7. **B** 衍生子对象；**A** 打开**历史与谱系**，看到投票、关闭与版本分组。

## 场景 C — 人类与 AI 接力（固定演示）

1. **A** 以读取、贡献、衍生权限邀请 **B**；**B** 加入。
2. **B** 打开 **AI 协作**。面板说明 AI 只会在 B 的成员权限与授权内行动，固定演示回复是脚本化的。
3. **B** 点击**让 AI 提议修改正文**。出现一条结构化提议，助手文本标记 `FIXTURE` 与 `structured`。
4. **B** 点击**应用提议**并确认。对象前进一个版本。
5. **B** 点击**让 AI 提议衍生**。出现确认卡，关联当前对象，显示拟议子标题、继承字段与**绑定到 v2**。
6. **B** 点击**批准并执行**并确认。服务端创建子对象；界面显示标题与直达链接。**B** 打开它。
7. **B** 打开子对象谱系，看到源对象。**A** 无法读取 B 的私有子对象，因此 A 的谱系只显示“没有对你可见的分支”，不会泄露标题。

预期：真实 Handoff、真实提议、真实版本绑定的人类确认、服务端执行与衍生边。没有调用模型提供方。

## 场景 D — 安全与诚实失败

在两个配置中执行：

| 检查 | 预期 |
|---|---|
| B 未受邀直接打开 A 的私有对象 URL | **无访问权限**；没有正文内容 |
| A 撤销待接受邀请，B 打开链接 | **这个邀请不可用。** |
| A 在 B 工作区打开时移除 B；B 刷新 | **你对这个对象的访问已经结束。** 不能再编辑 |
| B 有读取+贡献但无衍生；B 打开衍生 URL | **你的角色不包含衍生权限。** |
| A 在两个会话编辑同一版本；第二个保存 | **version_conflict** 警告；没有成功提示；草稿保留 |
| A 在私人上下文粘贴超过 8 KiB 中文 | 字节计数超过 8192；保存禁用 |
| 认证引导期间 API 返回 5xx | 带请求 ID 与**再试一次**的服务错误；不是假的退出登录 |

## 自动化验收

阻断式套件使用 Chromium 与 Firefox、两个独立上下文，并运行 390 px 移动项目。

```bash
npm ci
npx playwright install --with-deps chromium firefox
npm run test:e2e
```

本地如遇限流，只提高测试栈限制：

```text
RATE_LIMIT_AUTH_PER_MIN=1000
RATE_LIMIT_API_PER_MIN=600
```

CI 在工作流内覆盖 `.env`；生产默认值不变。必需检查为 **E2E**。
