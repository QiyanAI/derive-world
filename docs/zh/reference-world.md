# 开放参考世界

Derive World `v0.2.0` 是一个可自托管的活对象参考世界。它不是营销站点，也不是模拟：下面的每个界面都由仓库内同一套 Go API、PostgreSQL Schema、授权链和浏览器测试驱动。

> **状态：** `v0.2.0` 是 V2 产品阶段公开版本。固定演示模式是确定性演示输出，不是模型智能。真实 AI 仅对 DeepSeek `deepseek-flash` 上有记录的流程与发布源码树验证，不构成普遍 Provider 声明，见[发行说明](release-notes.md)。

![参考世界首页](../assets/g05-landing.png)

## 运行

```bash
git clone https://github.com/QiyanAI/derive-world.git
cd derive-world
cp .env.example .env
docker compose up --build -d
```

打开 <http://127.0.0.1:8080>。确定性适配器启用时，顶部显示 `FIXTURE`。

## 五个界面

| 界面 | 回答什么 |
|---|---|
| **世界** | 我是谁、我拥有或共享了哪些对象、什么在等我决定，以及它们如何连接？ |
| **对象** | 我能读取哪些活对象，我在每个对象中的角色是什么？ |
| **个人 AI** | 我的 AI 私人知道什么、有哪些会话、它能从对象收到什么？ |
| **数字自我** | 我授予了哪些授权、可以撤销什么、哪些操作需要我批准？ |
| **设置** | 语言、令牌、数据导出、部署模式与文档化限制。 |

### 首次使用

注册在同一个事务中创建用户、个人 AI 资料、空的私人上下文与默认授权。欢迎页展示真实状态，不会在后台偷偷创建示例数据。

![首次使用](../assets/g05-welcome.png)

世界页的每一步都根据服务端状态标记完成，而不是本地开关：对象存在、成员加入、会话存在或衍生边存在。

![世界仪表盘](../assets/g05-world-populated.png)

## 两种真实对象体验

### 协作对象

包含摘要、正文、清单与标签的文档。编辑是一次版本化操作；服务端检查 `expected_version`，不会静默覆盖。清单勾选与标签是独立操作，各自产生事件。

![协作对象](../assets/g05-collaborative.png)

### 互动对象

一个提示加 2–10 个选项。成员投票，第二次投票会移动回执，所有者关闭投票，关闭后的投票会被服务端拒绝。

![互动对象](../assets/g05-interactive.png)

## 邀请与加入

邀请授予明确权限：读取、贡献、衍生或邀请。链接只显示一次，只存储摘要。新用户可以从未登录的邀请页创建账户，并在注册后回到同一链接，因为 `next` 路由会贯穿注册流程。

![邀请预览](../assets/g05-invite-preview.png)

移除成员或撤销邀请会在下一次请求时生效。已打开的工作区会进入“访问已结束”状态，而不是继续渲染缓存内容。

## Handoff、提议、确认、衍生

个人 AI 永远不会拿到数据库。服务端根据你的成员权限与有效授权的交集生成有边界、只读的 Handoff。**成员与权限**中的预览展示成员级投影，并说明 AI 还会受到你授权的进一步限制。

![AI 提议](../assets/g05-ai-proposal.png)

固定演示模式下，脚本化提示一次只创建一个结构化操作：正文提议，或衍生请求。提议在被人类应用之前只是惰性数据。衍生请求是服务端创建的确认，绑定请求时的对象版本。

![人类确认](../assets/g05-ai-confirmation.png)

批准会在服务端执行一次。界面展示创建的对象并给出链接；拒绝不会改变对象。绑定版本过期会在批准前提示，若期间对象变化则以 `version_conflict` 拒绝。

![衍生子对象](../assets/g05-derived-child.png)

## 历史、谱系与隐私裁剪

历史分区按对象版本分组事件、人性化操作，并为每个版本提供“从该版本衍生”的入口。事件载荷放在渐进披露中。

![版本历史](../assets/g05-history.png)

谱系有边界，并按查看者可读范围裁剪。不可读的祖先显示为隐藏节点；不可读的后代被省略。当界面只能知道“对你不可见”时，绝不会声称“没有分支”。

![谱系](../assets/g05-lineage.png)

## 诚实的失败

客户端把封闭的 API 错误集映射为本地化解释，在技术细节中保留请求 ID，并在有意义的场景提供重试。版本冲突、访问被撤销、确认过期、容量限制、模型/能力失败与服务不可用都是不同状态。失败请求永远不会显示成功提示。

## 英文、中文与移动端

完整界面提供英文与中文消息目录，类型系统强制键集合一致。切换语言会更新 `<html lang>`、路由标题与所有界面，无需刷新。

![中文首页](../assets/g05-zh-landing.png)

在 390 px 宽度下，顶部导航变为可横向滚动的导航，对象分区仍可到达，谱系缩进受限，Playwright 断言 `scrollWidth` 不超过视口。

![移动端世界](../assets/g05-mobile-world.png)

## 刻意不做

- 确定性 Fixture 演示中的真实模型调用；Real AI 是独立的受控模式，仅对已批准的两次调用范围记为已验证。
- 实时协作；工作区在页面可见时轮询。
- 邮件、密码找回、OAuth 或账号删除。
- 托管服务、支付系统，或第二套身份、对象、权限、衍生、确认实现。

见[演示指南](demo-guide.md)与[限制](limitations.md)。
