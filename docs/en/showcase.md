# Showcase and sharing

The canonical English showcase, the current `v0.2.0` product recording, the
Create → Experience → Change → Derive → Share walkthrough, and the voluntary
submission guide are at the repository root:

- [Showcase — create, change, derive](../../SHOWCASE.md)

The showcase covers, in order:

1. **Create** — natural language becomes a human-approved, runnable world.
2. **Experience** — the same world can be played, read, worked in, watched or
   explored in 3D.
3. **Change** — the Personal AI proposes; a human applies the change.
4. **Derive** — an independent child from an immutable snapshot, with a
   permission-clipped lineage.
5. **Share** — a voluntary GitHub-native submission form, not an automatic
   collection system.

Current product surfaces:

- [v0.2.0 product recording](../../docs/assets/demo-v02-17s.webm) — a real
  Fixture-mode session. No model call.
- [Online product tour](https://qiyanai.github.io/derive-world/showcase/tour/)
  — a static, labelled tour with an interactive create/change/branch simulation.
- [Derive Relay](../../examples/worlds/README.md) — a reproducible base world
  and a voluntary derivation challenge using the existing publication and
  derivation paths.

The security, API and developer material remains available in
[the API guide](api.md), [security notes](security.md) and
[limitations](limitations.md). Publication and derivation are scoped to one
instance; there is no cross-instance federation or public import.

Older G05 screenshots and recordings remain in `docs/assets/` for historical
reference; the current product presentation uses `v0.2.0` Fixture captures from
the running product.
