# Owner action list — channel accounts

Only the account owner can complete these steps. The growth engine never asks for a password, one-time code or recovery code.

## GitHub (`github`)

- Status: owner-action-required
- [ ] Confirm the official organization and handle.
- [ ] Enable two-factor authentication and set a recovery email.
- [ ] Create a fine-grained token with the minimum scope.
- [ ] Approve the first public post.
- [ ] Create or select the official account/organization.
- [ ] Verify email and enable two-factor authentication.
- [ ] Create the minimum-scope token and place it in the secret store.
- [ ] Review and approve the first public post.
- [ ] Record who grants publishing authorization and its scope

## DEV Community (`devto`)

- Status: owner-action-required
- [ ] Register the official account and verify email.
- [ ] Enable two-factor authentication and set a recovery email.
- [ ] Create an API key and place it in the secret store.
- [ ] Approve the first article.
- [ ] Register the account and complete email verification.
- [ ] Generate an API key and place it in the secret store.
- [ ] Review and approve the first article.
- [ ] Record who grants publishing authorization and its scope

## Hacker News (`hacker-news`)

- Status: owner-action-required
- [ ] Register a personal account.
- [ ] Submit a Show HN manually when there is something testable.
- [ ] Respond to comments personally.
- [ ] Register and verify the account as a real person.
- [ ] Write and submit the Show HN manually.
- [ ] Enable two-factor authentication
- [ ] Set a recovery email
- [ ] Record who grants publishing authorization and its scope

## Reddit (`reddit`)

- Status: owner-action-required
- [ ] Register a personal account and enable two-factor authentication.
- [ ] Read each subreddit's self-promotion rules.
- [ ] Post manually only where the rules allow it.
- [ ] Register and verify the account.
- [ ] Enable two-factor authentication and set a recovery email.
- [ ] Review each subreddit's rules before posting.
- [ ] Post manually where the rules allow it.
- [ ] Record who grants publishing authorization and its scope

## Product Hunt (`product-hunt`)

- Status: owner-action-required
- [ ] Create the maker account and complete verification.
- [ ] Prepare the launch page and assets.
- [ ] Submit the launch manually.
- [ ] Enable two-factor authentication
- [ ] Set a recovery email
- [ ] Record who grants publishing authorization and its scope

When a step is complete, record the non-secret facts with `accounts record`. Never record a password, code or key.
