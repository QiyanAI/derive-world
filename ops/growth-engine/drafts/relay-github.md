# Derive Relay — One World. Infinite Possibilities.

Derive Relay is a voluntary derivation challenge. Start from one reproducible base world, derive in any direction you like, and share only what you choose to make public.

A Living Object is shared, versioned, and traceable. A derived world is independent and keeps its ancestry. [[fact:lineage]] Human approval is required for AI-proposed changes and derives. [[fact:human-approval]]

Rules:

1. Start from the base world in `examples/worlds/relay-base.json` and publish your derived world with derivation allowed.
2. Any form is valid: game, story, workspace, visual space, 3D scene or a custom surface. There is no fixed category to match. [[fact:what-it-is]]
3. Submit through the repository showcase issue form. Never include private context, conversations, tokens or another person's data.
4. Label the work Fixture or Real AI accurately. Fixture is deterministic demo output, not real AI. [[fact:fixture-not-real-ai]]
5. Participation is voluntary. There is no prize, no star requirement and no purchase.

Scope note: publication and derivation are scoped to one instance. There is no cross-instance federation or public import. [[fact:single-instance]]

## Facts used

- `what-it-is` — Derive World is an open-source foundation for Living Objects: shared, versioned objects that people and their Personal AI can read, contribute to, derive from, and trace through an explicit lineage.
- `human-approval` — A Personal AI can propose changes and derive children, but only a human can approve; a derived world is an independent child from an immutable snapshot.
- `lineage` — Derive creates an independent child from an immutable snapshot of the source; later edits to the parent do not propagate and the ancestry is recorded.
- `fixture-not-real-ai` — Fixture mode is a deterministic demo: it calls no model and is not real AI.
- `single-instance` — Publication, derivation and social features are scoped to one instance; there is no cross-instance federation or public import.
