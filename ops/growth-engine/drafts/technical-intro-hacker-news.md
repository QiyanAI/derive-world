# Derive World: objects with history, not chats with memory

Derive World is an open-source foundation for Living Objects: shared, versioned objects that a person and their Personal AI can read, contribute to, derive from, and trace. [[fact:what-it-is]]

## What is actually different

1. **A human and a Personal AI create together, and the human approves.** The AI can propose a change or a derive; nothing happens until a person applies it. [[fact:human-approval]]
2. **A world can be changed, played, read or operated without becoming a different product category.** One content, state, variable, permission, version and lineage model carries free-form worlds and their surfaces. [[fact:what-it-is]]
3. **Derivation keeps provenance.** A derived object is independent, and its ancestry is recorded. [[fact:lineage]]

## What you can run today

The repository is Apache-2.0 and self-hostable with Docker Compose. [[fact:open-source]] The quickstart runs in Fixture mode, which is deterministic demo output and **not real AI**. [[fact:fixture-not-real-ai]]

## What it is not

- Not a production platform, and no security certification is claimed. [[fact:not-production]]
- Not a cross-instance federation network. [[fact:single-instance]]
- Not a general provider benchmark; real-model evidence is scoped. [[fact:real-ai-scope]]

If you want to try it, the repository README has the supported local path.

## Facts used

- `what-it-is` — Derive World is an open-source foundation for Living Objects: shared, versioned objects that people and their Personal AI can read, contribute to, derive from, and trace through an explicit lineage.
- `human-approval` — A Personal AI can propose changes and derive children, but only a human can approve; a derived world is an independent child from an immutable snapshot.
- `lineage` — Derive creates an independent child from an immutable snapshot of the source; later edits to the parent do not propagate and the ancestry is recorded.
- `open-source` — The project is licensed under Apache-2.0.
- `fixture-not-real-ai` — Fixture mode is a deterministic demo: it calls no model and is not real AI.
- `real-ai-scope` — Real-model evidence is scoped to the documented flows on DeepSeek deepseek-flash; the release makes no general provider claim.
- `single-instance` — Publication, derivation and social features are scoped to one instance; there is no cross-instance federation or public import.
- `not-production` — This is a self-hostable OSS MVP, not a production platform, and no certification or adoption is claimed.
