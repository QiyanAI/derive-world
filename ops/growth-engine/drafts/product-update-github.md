# Derive World update

The project continues to develop free-form worlds with one content, state, variable, permission, version and lineage model. [[fact:what-it-is]]

The repository is Apache-2.0; the supported local path is Docker Compose. [[fact:open-source]] Fixture mode calls no model and is not real AI. [[fact:fixture-not-real-ai]]

See the release notes for the exact version and verification steps.

## Facts used

- `what-it-is` — Derive World is an open-source foundation for Living Objects: shared, versioned objects that people and their Personal AI can read, contribute to, derive from, and trace through an explicit lineage.
- `open-source` — The project is licensed under Apache-2.0.
- `fixture-not-real-ai` — Fixture mode is a deterministic demo: it calls no model and is not real AI.
