# Build something that derives

Derive World treats the object as the product: a Living Object has versions, members, permissions, and a traceable lineage. [[fact:what-it-is]]

A human and a Personal AI can co-create, but the human approves every change and derive. [[fact:human-approval]] Derived objects are independent and keep their ancestry. [[fact:lineage]]

To share a world, use the repository's showcase submission form. Publish only what you intend to be public, remove private context and tokens, and label the work **Fixture** or **Real AI** accurately. Fixture output is deterministic demo data, not real AI. [[fact:fixture-not-real-ai]]

You do not have to star, share, or submit anything to use the software.

## Facts used

- `what-it-is` — Derive World is an open-source foundation for Living Objects: shared, versioned objects that people and their Personal AI can read, contribute to, derive from, and trace through an explicit lineage.
- `human-approval` — A Personal AI can propose changes and derive children, but only a human can approve; a derived world is an independent child from an immutable snapshot.
- `lineage` — Derive creates an independent child from an immutable snapshot of the source; later edits to the parent do not propagate and the ancestry is recorded.
- `fixture-not-real-ai` — Fixture mode is a deterministic demo: it calls no model and is not real AI.
